# EduFlow

EduFlow is a School Management Information System built with pure Java.

## Technology Stack
- Java 25
- Maven
- PostgreSQL
- JDBC

## Architecture
- Model
- Repository
- Service
- Controller
- Security
- Configuration

## Planned Modules
- Schools
- Levels
- Classes
- Teachers
- Courses
- Students
- Authentication and Authorization
- Enrollment
- Attendance
- Exams and Grades
- Reports

Project initialization.
